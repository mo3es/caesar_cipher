# Caesar Cipher

A simple educational Java project implementing the classic Caesar cipher algorithm for text encryption, decryption, and cryptanalysis.

---

## 📌 About the Project

This project was created for educational purposes to practice core software development concepts (string manipulation, character processing, alphabet shifting) and working with the Git version control system.

**Key Features:**
* 🔒 **Encryption:** Encoding text with a specified key (shift).
* 🔓 **Decryption:**
  * Restoring text using a known key.
  * Automated recovery via **Brute Force**.
  * Automated recovery via **Frequency Analysis**.
* 🌐 **Alphabet Support:** Handles both Cyrillic and Latin alphabets (preserving character case and punctuation).

---

## 🛠 Tech Stack

* **Programming Language:** Java
* **Version:** Java 17+
* **Build / Execution:** Standard JDK (javac / java)

---

## 🚀 How to Run the Project

```bash

```

```Bash
javac Solution.java

```
