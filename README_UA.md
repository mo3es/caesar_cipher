# Caesar Cipher

Простий навчальний проєкт на Java, що реалізує класичний алгоритм шифрування Цезаря для шифрування, дешифрування та криптоаналізу текстів.

---

## 📌 Про проєкт

Цей проєкт створено з навчальною метою для практики базових концепцій розробки програмного забезпечення (маніпуляції з рядками, обробка символів, зсув алфавіту) та роботи з системою контролю версій Git.

**Ключові можливості:**
- 🔒 **Шифрування:** Кодування тексту за допомогою вказаного ключа (зсуву).
- 🔓 **Дешифрування:**
  - Відновлення тексту за відомим ключем.
  - Автоматичне відновлення за допомогою **Brute Force (грубої сили)**.
  - Автоматичне відновлення за допомогою **Частотного аналізу**.
- 🌐 **Підтримка алфавітів:** Підтримує як кириличні, так і латинські алфавіти (зберігаючи регістр символів та розділові знаки).
- 🧪 **Тестування:** Повністю покритий юніт-тестами JUnit 5.

---

## 🛠 Технологічний стек

- **Мова програмування:** Java 17+
- **Збирач проєкту:** Apache Maven (Shade Plugin для створення Fat JAR)
- **Фреймворк для тестування:** JUnit 5

---

## 🚀 Як запустити проєкт

### Варіант А: Швидкий старт (Готовий JAR-файл)
Якщо ви хочете просто запустити застосунок без компіляції з вихідного коду:
1. Завантажте останній зібраний `caesar-cipher-1.0-SNAPSHOT.jar` на сторінці [Releases](https://github.com/mo3es/caesar_cipher/releases).
2. Переконайтеся, що на вашому комп'ютері встановлено **Java 17+**.
3. Запустіть програму через термінал (як описано в пункті 4 нижче).

---

### Варіант Б: Збирання з вихідного коду (Для розробників)

#### 1. Клонування репозиторію
```bash
git clone [https://github.com/mo3es/caesar_cipher.git](https://github.com/mo3es/caesar_cipher.git)
cd caesar_cipher
```

### 2. Запуск юніт-тестів
```bash

mvn clean test
```

### 3. Збирання виконуваного JAR-файлу
```bash

mvn clean package
```

Це створить самодостатній файл caesar-cipher-1.0-SNAPSHOT.jar у директорії target/.

### 4. Запуск програми
```bash

java -jar target/caesar-cipher-1.0-SNAPSHOT.jar [mode] [source_file_path] [destination_file_path] [key]
```
Доступні режими (mode):

    encrypt / e — Зашифрувати текст із ключем

    decrypt / d — Розшифрувати текст із ключем

    brute-force / brute — Автоматичне відновлення за частотою слів

    frequency-analysis / freq — Автоматичне відновлення за частотою літер
    

Примітка: Якщо ви запустите jar-файл без аргументів, автоматично запуститься інтерактивний режим командного рядка.
