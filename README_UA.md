# Caesar Cipher (Шифр Цезаря)

Простий навчальний проєкт, що реалізує алгоритм класичного шифрування та розшифрування тексту за допомогою **шифру Цезаря**.

---

## 📌 Про проєкт

Цей проєкт створений у навчальних цілях для практики базових концепцій програмної розробки (обробка рядків, робота з символами, зсуви в алфавіті) та роботи з системою контролю версій Git.

**Основні можливості:**
* 🔒 **Зашифрування:** кодування тексту із заданим ключем (зсувом).
* 🔓 **Розшифрування:**
    * відновлення початкового тексту за відомим ключем.
    * відновлення початкового тексту методом "Brute force".
    * відновлення початкового тексту методом частотного аналізу.
* 🌐 **Підтримка алфавітів:** робота з кирилицею та/або латиницею (із збереженням регістру та розділових знаків).

---

## 🛠 Технології

* **Мова програмування:** Java
* **Версія:** Java 17+ 
* **Збірка:** Стандартний інтерпретатор
